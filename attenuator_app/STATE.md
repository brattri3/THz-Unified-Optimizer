## Отношения с A4 — ВАЖНО, поправка к записи от 2026-07-28

В `ACTIVITY.md` Сессия A планирует `A4_attenuation_calc` как «API для C» и делает вывод:
«до готовности A4 запуск C преждевременен». Первая редакция этого STATE записала
`C2_a4_integration` как `blocked`.

**Фактически C не заблокирована и никогда не была.** У `attenuator_app/core/` собственная
реализация: `blanco.py` (векторизованный Бланко + Друде, LRU-кэш), `forward.py` (схемы S0–S3),
`inverse.py` (обратная задача). Она валидирована на 69 точках реальных измерений; прибор
#02721 продан, но программа НЕ выпущена — ждёт ручной приёмки владельцем (release gate выше).

Это значит, что в репозитории **две независимые реализации** расчёта затухания. Предлагаемое
разделение (решает ORCH/владелец, запрос — в `HANDOFFS.md`):

| | Сессия A (`research/two_wgp/`) | Сессия C (`attenuator_app/core/`) |
|---|---|---|
| Назначение | физический эталон, проверка гипотез | продуктовый расчёт для оператора |
| Модель | двух-WGP Джонс, per-element геометрия | схемы S0–S3, паспортная формула |
| Что важно | точность, идентифицируемость | воспроизводимость, границы применимости, интервал |
| Приоритет | истина | не соврать оператору |

Тогда C2 — не «интеграция», а **сверка**: прогнать оба калькулятора на одной сетке и
задокументировать расхождение. Расхождение больше паспортной RMSE 1.39 дБ — сигнал, что
в одной из реализаций ошибка. Это приёмочная проверка для обеих сессий, а не зависимость.

Побочный физический результат, ценный вне зоны C: разница между сеансами, где вращался
ПЕРВЫЙ поляризатор (series1-3), и где ВТОРОЙ (356att), составила **+0.15 дБ**. Закон Малюса
на этом железе выполняется — затухание задаётся относительным углом. Продублировано в
`research/logs/RESEARCH_LOG.md` с тегом `[C]`.

## Два ключевых решения, которые нельзя потерять

**1. Относительный режим — по умолчанию, и это физика, а не удобство.**
При SET ZERO общий множитель потерь `ℓ(ν)` и вносимое затухание `|t⊥|⁴` сокращаются
тождественно, остаётся только `t∥_eff/t⊥`. Проверено численно: `|dA| = 1.8e-15` дБ при
изменении `loss`/`gamma`. Следствие — **хуже всех определённый параметр `gamma` из
относительного режима выпадает**, поэтому экстраполяция за полосу калибровки в нём
на порядок надёжнее, чем в абсолютном.

**2. Неопределённость берётся по разбросу МЕЖДУ СЕАНСАМИ, а не по ковариации одного фита.**
По всем трём подгоняемым параметрам разброс между сеансами победил паспортный 95 % CI —
он в 3–27 раз шире. Паспортный интервал получен на отфильтрованном по дрейфу ансамбле и
оптимистичен для повседневной работы, где прибор переставляют и заново юстируют.
Валидация подтвердила выбор: 69/69 при запасе ×1.67.

## Допущения, требующие подтверждения владельцем

1. Граница апертур 45 мм для выбора деления шкалы (2°/1°) — взята по технологическому
   делению Tydex (плёнки D25-45 и D50-100). Для ATT-11-16-CA85 (85 мм) роли не играет:
   деление 1° подтверждено владельцем.
2. `gamma = 1.58` заморожен (паспортное значение), диапазон 1.0…2.5 для огибающей.
   Свободный фит даёт 4.18 — для экстраполяции вверх непригодно, параметр вырожден с утечкой.
3. Штраф за экстраполяцию 1 дБ на октаву за полосой — величина эмпирическая.
4. Плёночные поляризаторы Tydex учитываются только в схеме S3 (`use_film`); в паспортной S0
   не участвуют.
5. `D_eff = 5.67` мкм трактуется как ширина эквивалентной плоской полоски (модель Бланко
   отображает круглую проволоку D=11 мкм на полоску ≈D/2), НЕ как геометрический диаметр.
   Связано с открытой «загадкой D_eff» (`research/SYNTHESIS.md`) — C её не решает и не должна.
6. Схема S0 (паспортная формула) принята как способ, которым покупатель реально использует
   прибор. Не подтверждено.
