# Как запустить автономный ночной прогон

## Режим: bypass permissions + /loop self-paced + работать до лимитов

### Шаг 1. Перезапустить Claude Code в bypass-режиме
Закрой текущую сессию и запусти из корня проекта:
```powershell
cd "C:\Users\pop\Antigravity IDE"
claude --dangerously-skip-permissions
```
(Флаг снимает подтверждения на выполнение — нужен для непрерывной ночной работы. Страховка — гардрейлы в RESEARCH_PLAN.md §6.)

### Шаг 2. Запустить самотемпируемый цикл
Вставь ОДНОЙ строкой (это директива для /loop без интервала = self-paced):
```
/loop Автономное исследование THz-WGP. Каждую итерацию: прочитай THz-Unified-Optimizer/research/state.json, возьми первую задачу не в статусе done, выполни ОДИН атомарный шаг (скрипты в research/experiments/, запуск через .venv), запиши результат с числами в research/logs/RESEARCH_LOG.md, обнови state.json. Соблюдай гардрейлы RESEARCH_PLAN.md §6 (только чтение оригиналов, никаких rm -rf/git push/сети). После T7 продолжай генерировать и тестировать новые гипотезы, пока не упрёшься в лимиты. При блокировке — залогируй BLOCKED и переходи к следующей исполнимой задаче.
```

### Шаг 3. Уйти домой
Я буду сам продолжать по очереди задач, вести лог и обновлять состояние. Утром смотри:
- `research/logs/RESEARCH_LOG.md` — хронология
- `research/SYNTHESIS.md` — итоговый отчёт (появится после T7)
- `research/hypotheses/HYPOTHESES.md` — вердикты по гипотезам
- `research/results/` — артефакты, графики, метрики

### Если прервётся
Просто повтори Шаг 2 — состояние в `state.json` возобновит работу с места.
