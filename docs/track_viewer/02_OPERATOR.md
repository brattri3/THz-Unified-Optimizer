# Гайд оператора: track_viewer у прибора

Короткий рабочий документ для человека за спектрометром. Подробности форматов и чисел —
`01_FORMATS.md`; здесь только порядок действий.

Инструмент **не заменяет** `MEASUREMENT_ORDER.md` и предполётный чек-лист: центровку
образца проверяют руками, программа этого не видит.

---

## Перед прогоном: разложить дорогу

1. `start.bat` → кнопка **«разложить дорогу…»**.
2. Указать **пустой** каталог для нового прогона и имя образца.
3. Задать план. По умолчанию стоит проверенная схема `test_grid_33_11`:
   яркий якорь `0°`, тень `80…100°` шагом `2°`, яркая зона `±70°` шагом `10°`,
   зеркальная тень `−80…−100°`, повтор тени обратным ходом, референс каждые 3 трассы.
4. **ПРЕДПРОСМОТР** — справа появится полный список файлов в порядке съёмки.
5. **СОЗДАТЬ ФАЙЛЫ** — кнопка активна только после предпросмотра и гаснет при любой
   правке параметров.

Создаются **только пустые файлы** плюс `META.txt` и `README.md` с планом.

> **Заполнить `META.txt` до начала съёмки.** Без полей геометрии установки потом нельзя
> отличить «изменилась физика» от «съехал образец». Окно сканирования выбрать один раз и
> не менять в течение прогона.

### Если инструмент отказался создавать файлы

Значит в каталоге нашёлся **непустой** файл с плановым именем. Не создано ничего — ни
одного файла. Это защита, а не сбой: цена ошибки — затёртые измерения, которые нельзя
восстановить. Взять другой каталог или разобраться с этим вручную.

## Во время прогона

Следующий незаполненный файл и есть следующее действие — он показан в левой панели
строкой «следующий:».

После того как прибор **дописал** трассу, нажать **ОБНОВИТЬ**. Автообновления по таймеру
нет намеренно: чтение каталога в момент записи вернуло бы обрезанный файл.

### На что смотреть

| Панель | Что должно быть |
|---|---|
| `T(θ)` линейная | гладкий колокол с максимумом у яркого якоря |
| `T(θ)` в дБ | ровное «дно» в зоне гашения; разброс точек дна ≈ повторяемость |
| `T(ν)` в дБ | зелёная кривая заметно выше серого пунктира до ~1.5 ТГц |

Серый пунктир — **шумовой пол**. Там, где зелёная кривая на него ложится, измерять уже
нечего, и «структуру» спектра выше этого места читать нельзя.

### Красные сигналы — остановиться и разобраться

* **точка прижата к единице и окрашена красным.** `T > 100 %`. Скорее всего перепутаны
  образец и референс, либо образец сместился между трассой и фоном. Именно так
  `test_grid_40_20` дал `105.7 %`, и это едва не ушло в отчёт;
* **дно в дБ поползло** между `rep1` и `rep2` одной и той же тени — дрейф установки;
* **пик образца уехал** относительно референса больше чем на несколько сотых пикосекунды
  — образец или оправа сдвинулись;
* **«референсы расходятся по энергии»** — между двумя соседними фонами что-то изменилось,
  усреднять их нельзя;
* **«файл не разобран»** — трасса записалась испорченной, переснять.

## Настройки: что менять, а что нет

**Оставить как есть, если нет причины:**

* **DC: предымпульс 15 %** — рабочий режим. Вычитает постоянное смещение детектора;
* **референс: ближайший ранний** — этим же правилом пользовалось ядро проекта;
* **окно: выключено** — включать только чтобы посмотреть, что даёт отсечение эха.

**Режим «DC: нет (как в ядре)» — только для сверки чисел с расчётами проекта.**
В зоне гашения он завышает пропускание **в 121 раз** (18.3 % вместо 0.15 %): у тёмной
трассы 99 % сырого интеграла даёт смещение детектора, а не импульс. Программа предупредит
об этом сама, но по угловому графику ошибку легко принять за физику — дно поднимется до
`0.18` и зона гашения просто исчезнет.

## Выгрузка

**«сохранить трек в CSV»** — колонки `seq, file, angle_deg, rep, reference, energy_sig,
energy_ref, T, T_dB, peak_sig_ps, peak_ref_ps, warnings`, разделитель `;`. Для вёрстки в
Origin Pro.

Консольный режим (`console.bat`) даёт то же самое без окна:

```
python -m track_viewer.cli C:\путь\к\прогону --csv трек.csv
python -m track_viewer.cli C:\путь\к\прогону --seq 47      подробности по одной трассе
```

## Если что-то сломалось

Запустить `selftest.bat`. Ожидается `=== пройдено 19 из 19 ===` и строка

```
без DC          T = 98.9089 %  ← число ТЗ §7.2
```

Если число другое — программа разошлась с ядром проекта, дальше не идти. Прислать вывод
самопроверки целиком.

## Управление

| Действие | Как |
|---|---|
| перебрать измерения | слайдер, `←` `→`, `PgUp` `PgDn` (на 10) |
| перейти к номеру | поле справа от слайдера — **сквозной номер файла**, не позиция |
| выбрать точку мышью | щелчок по угловому графику |
| зум, панорама, сохранить PNG | панель инструментов над слайдером |
