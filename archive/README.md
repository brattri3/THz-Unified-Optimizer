# archive/ — замороженные слои проекта

Сюда переезжает то, что **было рабочим механизмом проекта, а стало историей**: отменённые
регламенты, журналы мёртвых инструментов, документы перекрытых эпох.

## Правила каталога

1. **Не исполнять.** Ничто отсюда не является действующим правилом или инструкцией, даже если
   написано в повелительном наклонении. Действующие правила — `CLAUDE.md` +
   `coordination/CHARTER.md` + `coordination/PROJECT.md`.
2. **Не пополнять** содержимое уже заархивированных подкаталогов: архив фиксирует состояние на
   дату, а не продолжает жить.
3. **Не удалять.** Архив существует, чтобы можно было ответить «почему в проекте так сложилось»
   без раскопок в `git log`.
4. Каждый подкаталог обязан иметь свой `README.md`: что это было, почему заморожено, что из
   этого сохранено в действующих правилах.
5. Имя подкаталога — `<что>-<год-месяц заморозки>`.

## Владелец

Каталог принадлежит роли **ORCH** (`coordination/OWNERSHIP.md`). Другие роли — read-only;
предложение что-то заархивировать идёт через `coordination/QUESTIONS.md`.
