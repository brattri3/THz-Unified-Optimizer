## Перед стартом

Заполнить `META.txt` — без полей геометрии установки нельзя отличить
«изменилась физика» от «съехал образец». Окно сканирования выбрать один раз
и не менять в течение прогона.

## Про `dark`

Файлы `NNN_dark.txt` снимаются при **перекрытом пучке** — непрозрачная
преграда на пути излучения. Это шум закрытого тракта: по нему оценивается
шумовой пол и динамический диапазон, независимо от метода Нафтали по
высокочастотному хвосту спектра.

**Из трасс dark НЕ вычитается ни при каких настройках.** Шум некогерентен:
вычитание его из поля не убрало бы шум, а добавило второй независимый
экземпляр. Записать в `META.txt`, чем именно перекрывался пучок.
