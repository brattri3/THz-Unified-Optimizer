## Граница B↔A: ПО СЛОЮ, а не по каталогу (решение ORCH, 2026-07-28)
Инвариант, который защищаем, лежит **по слоям**, а не по каталогам:
- **B = общее численное ядро** (`model_core`, `fit_lib`, `verify_*`) + ревьюер эквивалентности.
- **A = скрипты-эксперименты/гипотезы поверх ядра** (`tN_*.py`, `model_m5`), пишет их сам, без хэндоффа.
- **Инвариант CHARTER:** второй копии Бланко/грида/невязки/билдера не заводить — звать `model_core`;
  форк только через хэндофф с обоснованием. Проверяется машинно в `verify_model_core.py` (B добавляет
  поиск прямых вызовов `compute_t_perp`/`compute_theoretical_grid_2d` вне ядра).
- **`GEOMETRY` вынести** из `fit_lib.py` в `research/experiments/geometry.py` (данные образцов, зона A).
- B параметризует `build_experiment(data, angles_limit=None)` (дефолт = `config.ANGLES_LIMIT_2D`),
  A зовёт с `angles_limit=(-90,90)` — вместо шестой копии фильтра углов; повод схлопнуть 5 существующих.

## Граница D↔L по литературе (решение ORCH, 2026-07-29) — чтобы «обзор» не писали двое
Обе сессии касаются литературы, но делают РАЗНОЕ; файлового конфликта нет (разные зоны), роли разведены:
- **L = поиск и извлечение (первичка), зона `research/literature/**`.** Находит статьи (metasearch, граф
  цитирований), держит corpus/PDF, извлекает факт-выжимки (DOI, ключевая формула/метод/параметр,
  ограничения) в `INDEX.md`, `litrev/RETROSPECTIVE_REVIEW.md`, `LITERATURE_REVIEW.md`, `corpus/`.
  L — источник истины «что говорит литература». Пишет **обзор ПОЛЯ** (широкий, фактологический).
- **D = синтез для статьи (вторичка), зона `research/paper/**`.** Пишет раздел обзора/Related Work
  СТАТЬИ и учебные `primers/`, опираясь на выжимки L; отбирает, интерпретирует, позиционирует новизну.
  Пишет **обзор ДЛЯ СТАТЬИ** (узкий, аргументный). Первичный поиск/массовое извлечение сам НЕ ведёт.
- **Механизм связи:** нужны источники/выжимки, которых нет в `research/literature/**` → D пишет
  структурированный запрос `ОТ D К L` в `HANDOFFS.md` (тема, конкретные вопросы, требуемые поля
  выжимки, глубина графа). L отвечает в своей зоне, D синтезирует. Так «кто пишет обзор» снят как спор:
  L — обзор поля, D — обзор для статьи.
