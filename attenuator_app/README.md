# attenuator_app — прототип v0.2

Расчёт ТГц-аттенюатора **ATT-11-16-CA85** на двух проволочных поляризаторах:
прямая задача, обратная задача, границы применимости. CLI + встраиваемая библиотека.

Проектная документация — `docs/attenuator_app/` (7 документов).

## Запуск

```powershell
cd "C:\Users\pop\Antigravity IDE\THz-Unified-Optimizer"

.venv\Scripts\python.exe -m attenuator_app.selftest          # 13 приёмочных проверок
.venv\Scripts\python.exe -m attenuator_app.tools.validate    # проверка на 6 сеансах измерений
```

## Паспорт прибора

`passports/ATT-11-16-CA85_02721.json`. Источник истины — **официальный паспорт
продукта** `THz-Spectroscopy-Python-Manual2/text/passport.tex` (S/N #02721).

```
апертура   85 мм (clear aperture)  ->  шкала 1 град, sigma(угол) 0.71 град
P_eff      15.500 +- 0.026 мкм                [паспорт, 95 % CI]
D_eff       5.670 +- 0.249 мкм                [разброс между сеансами]
loss        0.255 +- 0.142 дБ/ТГц^1.58        [разброс между сеансами]
offset     -0.450 +- 0.958 град               [разброс между сеансами]
RMSE модели 1.39 дБ (паспортная, до -45 дБ)
полоса     0.05-2.0 ТГц, схема S0, детектор когерентный (Scenario A)
```

Прибор — **два независимых проволочных поляризатора**; первый выровнен по
поляризации пучка, вращается второй (анализатор). Затухание задаётся
относительным углом `theta = theta2 - theta1`.

`D_eff = 5.67` — ширина эквивалентной **плоской полоски**: модель Бланко
отображает круглую проволоку `D = 11` мкм на полоску шириной примерно `D/2`.
Это не геометрический диаметр.

**Неопределённости: берётся максимум из паспортного 95 % CI и разброса между
сеансами.** По всем трём подгоняемым параметрам победил разброс между сеансами —
он в 3–27 раз шире паспортного интервала. Паспортный получен на отфильтрованном
по дрейфу ансамбле и оптимистичен для повседневной работы, где прибор
переставляют и заново юстируют.

Формулы паспорта Scenario A / Scenario B — это в точности `detector=coherent`
и `detector=power` в программе (проверено алгебраически и численно).

## Валидация на реальных измерениях

`tools/validate.py` — шесть сеансов одного прибора, относительный режим, SET ZERO на 0°:

```
356att      19/19 = 100 %      (вращался ВТОРОЙ поляризатор)
series1     19/19 = 100 %      (вращался ПЕРВЫЙ)
series2     19/19 = 100 %
series3     12/12 = 100 %
series4,5   пропущены (по одному углу)

ИТОГО покрытие 95 % интервала: 69/69 = 100.0 %
смещение (изм - модель): +0.35 дБ, RMSE 1.23 дБ
  вращался второй: смещение +0.46 дБ, RMSE 1.47 дБ
  вращался первый: смещение +0.31 дБ, RMSE 1.12 дБ
  -> разница между группами +0.15 дБ
запас интервала: полу-ширина 4.01 дБ против необходимых 2.40 дБ  -> x1.67
```

Три вывода:

1. **Заявленные 95 % подтверждаются** — 69 из 69 точек внутри интервала.
   Запас x1.67 означает, что интервал сознательно широк (как и требовалось).
2. **RMSE 1.23 дБ против паспортной 1.39 дБ** — независимое согласие с
   документом прибора.
3. **Разница между «вращался первый» и «вращался второй» — 0.15 дБ.** Закон
   Малюса на этом железе выполняется: затухание определяется относительным
   углом, а не тем, какой поляризатор крутить.

## Сеансы работы

Каждый запуск CLI создаёт папку `runs/<дата>_<время>_<uid>[_tag]/`:

```
meta.json    все выборы пользователя (паспорт, схема, детектор, источник, вес,
             режим, ноль, полоса, шкала) + история их изменений с метками времени
log.txt      журнал введённых команд
plots/       ASCII-графики, каждый с шапкой контекста
figures/     PNG-графики (matplotlib), с подписью-контекстом под полем
data/        те же данные в CSV, с той же шапкой
```

Графики строятся по правилам дизайн-системы, палитра прошла валидацию
(3 слота, all-pairs: CVD ΔE 9.2, normal-vision ΔE 24.0). Сознательные ограничения:
никаких двух осей Y — вторая величина уходит на отдельную панель; зоны применимости
не «ещё один цвет серии», а статусная палитра, и всегда подписаны словами;
экстраполяция кодируется вторым каналом (пунктир), а не только цветом.
Команда `ascii off` убирает псевдографику из терминала, PNG продолжают писаться.

Причина: число в дБ без контекста не интерпретируется задним числом — от какого
нуля отсчитано, каким паспортом, в какой схеме, с каким весом источника.
Отключается флагом `--no-session`, корень задаётся `--runs`, суффикс — `--tag`.

## Библиотека

```python
from attenuator_app.api import Attenuator

att = Attenuator.from_passport("attenuator_app/passports/ATT-11-16-CA85_02721.json")
att.set_zero(0.0)

r = att.attenuation(theta_deg=60)
print(r["att_db"], r["ci95_db"])

for s in att.solve(target_db=20):     # все ветви, ранжированы
    print(s)
for c in att.checks(target_db=20):    # F0..F8 с предложением средства
    print(c)
for cmd in att.motion_plan(att.solve(20)[0]):
    print(cmd.as_operator_instruction())
```

`MotionCommand` — точка расширения под моторизацию. Сейчас прибор с ручной
установкой угла, поэтому команда печатается оператору; когда появится привод,
тот же список уйдёт в драйвер без изменения вызывающего кода.

## Допущения, требующие подтверждения

1. **Граница апертур 45 мм** для выбора деления шкалы (2 / 1 град) — взята по
   технологическому делению Tydex (плёнки D25-45 и D50-100). Для этого прибора
   (85 мм) роли не играет: деление 1 град подтверждено владельцем.
2. `gamma = 1.58` заморожен (паспортное значение), диапазон 1.0…2.5 для огибающей
   экстраполяции. Свободный фит даёт 4.18, что для экстраполяции вверх непригодно —
   параметр вырожден с утечкой.
3. Штраф за экстраполяцию — 1 дБ на октаву за полосой; величина эмпирическая.
4. Плёночные поляризаторы Tydex учитываются только в схеме S3 (`use_film`),
   в паспортной схеме S0 они не участвуют.
