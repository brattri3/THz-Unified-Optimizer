# rationale/ — почему решения приняты именно так

**В контекст при старте не грузится.** Сюда заглядывают, когда правило неочевидно, кажется лишним
или его собираются изменить. Действующие правила — в `CLAUDE.md`, `CHARTER.md` и `roles/<ID>.md`;
здесь только обоснования, вынесенные оттуда 2026-08-15 при переходе на трёхуровневый старт.

| Файл | Отвечает на вопрос |
|---|---|
| `PARALLEL_WORK.md` | почему координация сессий отдана штатным механизмам Claude Code и чем был плох самодельный лок |
| `BACKGROUND_WORKERS.md` | зачем каждый из четырёх пунктов записи о запуске фонового работника |
| `ZONES_HISTORY.md` | как складывались границы зон: санкции владельца и решения ORCH |
| `BOARD_VOLUME.md` | ⚠ **отменённый** регламент объёма доски — сохранён как история проблемы |

Правило каталога: **ничто отсюда не является инструкцией к исполнению.** Если текст здесь
противоречит `CHARTER.md`, прав `CHARTER.md`, а расхождение — повод сказать ORCH.
