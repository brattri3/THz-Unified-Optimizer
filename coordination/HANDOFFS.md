- **Повод.** В `ACTIVITY.md` A планирует `A4_attenuation_calc` как «стабильную библиотеку + тонкий
  CLI» для C и заключает: «до готовности A4 запуск C преждевременен». Вывод основан на неполных
  данных: C не ждала A4 и не заблокирована.
- **Факт.** `attenuator_app/core/` содержит собственный рабочий расчёт: `blanco.py`
  (векторизованный Бланко + Друде, LRU-кэш), `forward.py` (схемы S0–S3), `inverse.py` (обратная
  задача, все ветви, привязка к делениям шкалы). Валидировано на 69 точках реальных измерений
  (покрытие 95 % интервала 69/69, RMSE 1.23 дБ против паспортной 1.39 дБ). Прибор
  ATT-11-16-CA85 #02721 продан и отгружен; приложение обслуживает его уже сейчас.
- **Следствие.** В репозитории две независимые реализации расчёта затухания. Это не обязательно
  плохо — у них разные критерии качества, — но разграничение нужно зафиксировать, иначе A
  потратит итерации на API, потребителя у которого нет.
- **Что предлагаю** (решение за ORCH/владельцем, C ничего в зоне A не трогает):
  - **A4 = физический эталон.** Двух-WGP Джонс с per-element геометрией; критерий — точность и
    идентифицируемость. Потребитель — сама A (гипотезы) и D (статья).
  - **`attenuator_app/core` = продуктовый расчёт.** Критерий — воспроизводимость, честные границы
    применимости, консервативный интервал. Потребитель — оператор прибора.
  - **C2_a4_crosscheck вместо интеграции:** прогнать оба калькулятора на одной частотно-угловой
    сетке и задокументировать расхождение. Это приёмочная проверка для ОБЕИХ реализаций.
- **Критерий готовности:** таблица расхождений `A4` vs `core` на сетке 0.2–1.5 ТГц × 0–90°.
  Порог тревоги — расхождение больше паспортной RMSE 1.39 дБ: значит, где-то ошибка.
  Сверку готова выполнить C (в своей зоне, A4 только читается) — как только A4 появится.
- **Что может пригодиться A прямо сейчас** (всё read-only, делать ничего не нужно):
  валидация C — независимая проверка закона Малюса на железе. Сеансы, где вращался ПЕРВЫЙ
  поляризатор (series1-3), и где ВТОРОЙ (356att), разошлись на **+0.15 дБ**. Для A6/A3, где
  разбирается вырожденность `angle_offset ↔ φ2 ↔ ε_cross`, это верхняя граница на любую
  асимметрию «первый/второй элемент» в этих данных. Скрипт — `attenuator_app/tools/validate.py`.
- Статус: open
