# Аттенюатор из двух WGP — измерения (356att, series1–5)

Здесь лежат THz-TDS измерения **аттенюатора из ДВУХ проволочных поляризаторов (WGP)** в ротаторах.
Это НЕ то же, что одиночные WGP (specac / test_grid_40_20 / purewave / будущий test_grid_33_11 —
они «один WGP между двумя плёночными», см. `data_pool/DATASETS.md`). Аналог MEASUREMENT_ORDER.md,
но описывает конфигурации уже снятых серий (метаинформация со слов владельца, 2026-07-27).

Файлы грузятся `DataManager` по имени `{dataset}_{angle}deg_rep{N}_{sig|bg}.txt` независимо от
подпапки (рекурсивный поиск) — перенос сюда пути в скриптах не ломает.

---

## Общая схема прибора (аттенюатор)
Цепочка: `эмиттер → [вход. плёнка] → WGP_A → WGP_B → [вых. плёнка] → детектор`.
- Два WGP в ротаторах; ОДИН вращается (сканируемый угол θ), другой статичен (макс. пропускание).
- Плёночные поляризаторы (TYDEX) на входе/выходе — в части серий (см. таблицу). Спецификации плёнок ниже.
- **ВНИМАНИЕ:** в 356 и series1–3 вращается РАЗНЫЙ WGP (см. таблицу) → это РАЗНЫЕ прямые модели.

## Плёночные поляризаторы (TYDEX ТГц, из `TYDEX_ ТГц поляризаторы.html`)
Проволочная сетка на плёнке, 2 варианта. В НАШЕМ ТГц-диапазоне (λ≈200–1500 µm ⊂ «250–3000 µm»):
- Пропускание нужной поляризации **K1 > 80 %** (15–3000 µm).
- Экстинкция **E = K1/K2 > 8500…55000** (250–3000 µm) = **> 39…47 дБ** в нашем диапазоне.
  (В худшем углу 15–250 µm: E > 250…350, т.е. > 24…25 дБ.)
- Степень поляризации **P1 = (K1−K2)/(K1+K2) > 99.97 %** (250–3000 µm).
⇒ Плёнки в ТГц **практически идеальны** (утечка K2 ~1e-2…1e-4). В модели их можно брать
идеальными проекторами (малая поправка), в отличие от WGP, которые заметно течут.

## Научные следствия (важно для анализа/Session A)
1. **Одиночная-WGP 2D-модель (`cos²·t_perp + sin²·t_par`) НЕВЕРНА для 356/series1–3** — там анализатор
   это РЕАЛЬНЫЙ WGP (WGP_B/WGP_A), не идеальная плёнка. Нужна двух-WGP Джонс-модель (Session A,
   `research/two_wgp/`). Прошлые фиты 356 одиночной моделью → пересмотреть.
2. **Но D_eff-редукция есть и у корректно-моделированных ОДИНОЧНЫХ образцов** (specac D_eff/D_phys≈0.45,
   test_grid≈0.64 — там модель адекватна: один WGP + почти идеальные плёнки). ⇒ загадка D_eff — НЕ
   только артефакт второго WGP; часть эффекта реальна и для одиночного WGP. Session A должна это
   развести: двух-WGP модель чинит 356/series, но одиночная редукция требует своего объяснения.
3. **series4/5 исключить** из первичных фитов (артефакты). series1 (без плёнок) — чистейший тест
   двух-WGP модели (нет плёночных поправок). series2/3 = series1 + плёнки (проверка вклада плёнок).
4. **Отрицательные углы уже есть** в 356/series1 (−90…+90) — готовый материал для калибровки офсета и
   теста асимметрии (см. обсуждение negative-angle в purewave).
5. Что «вытащить про аттенюатор»: экстинкция прибора A(θ)=U(θ)/U(θ_max), положение макс.пропускания и
   скрещённого (офсет), спектр экстинкции, параметры двух-WGP модели (t_par обоих, углы), сравнение
   с предельным Малюсом cos²(θ_A−θ_B). Это и есть основа софта затухания (Session A, задача A4).

## ПОДТВЕРЖДЁННЫЕ ОТВЕТЫ (владелец, 2026-07-27)
- **356: ВЫХОДНОЙ плёнки НЕТ** (перед детектором плёночного поляризатора нет). Схема 356:
  `эмиттер → вход.плёнка(гориз) → WGP_A(статичен) → WGP_B(вращается) → детектор`.
- **Оба WGP аттенюатора ИДЕНТИЧНЫ**, паспорт: **шаг P=16 µm, диаметр проволоки D=11 µm** (D/P=0.6875).
- ⇒ series1–3 — тот же аттенюатор → **геометрия ИЗВЕСТНА (P=16, D=11)**; добавлена в fit_lib.GEOMETRY.
  (356att в анализе Фаз 1–3 шёл с P=15.5 — базовая линия; паспорт=16, расхождение ~3%, legacy сохранён.)
- Плёнки вход/выход в series2/3 — те же TYDEX (почти идеальны). series1 — без плёнок.
Разблокировано: series1–3 можно фитить с известной геометрией (одиночная модель ≈ валидна по теореме A1,
т.к. статичный WGP_B выровнен с детектором = идеальный анализатор × t_perp2(ν)).
