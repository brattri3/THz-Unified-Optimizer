# Линеаризация закона Малюса для неидеального поляризатора с утечкой

**Сессия A · задача `A0_malus_linearization` · 2026-07-29**
Код: `research/two_wgp/malus_linearization.py` (самопроверка 12/12)
Артефакты: `research/results/two_wgp/a0_malus_linearization.json`, `a0_malus_harmonics_data.json`

---

## 0. Ответ в двух фразах

**Да, метод существует, и он точный, а не приближённый.** Наблюдаемая нелинейна по *углу*, но
линейна по *коэффициентам*, если разложить её по гармоникам угла; тогда подгонка — обычный линейный
МНК с замкнутой формулой, единственным минимумом и аналитической ковариацией.

**Но у него две редакции, и учебная — неправильная для нашей установки.** Классическая
3-параметрическая форма `a0 + a1·cos2θ + b1·sin2θ` верна для *интенсивностной* (некогерентной)
композиции. Наша модель складывает **поля**, а потом возводит в квадрат, и тогда точный линейный
базис — **пятимерный**, с четвёртой гармоникой. Именно она несёт фазу утечки, то есть `τ_leak`.

## 1. Словарь (термины определяются при первом употреблении)

| Символ | Что это |
|---|---|
| θ | угол поворота поляризатора, град. Конвенция репозитория: **ось пропускания** (⊥ проводам) |
| U(θ) | наблюдаемая мощность (энергия Парсеваля `Σ_ν |T(θ,ν)|²` либо `|T|²` на одной частоте) |
| `t_perp` | комплексный коэффициент пропускания **яркого** канала (поле ⊥ проводам) |
| `t_par` | то же для **тёмного** канала — это и есть «утечка» |
| η | амплитудная утечка `|t_par| / |t_perp|` (в M5 обозначает то же самое) |
| Δφ | относительная фаза `arg(t_perp) − arg(t_par)`; в M5 это `δ₀ + 2πν·τ_leak` |
| θ₀ | угловой офсет — нуль шкалы поворотного столика относительно физической оси |
| ER | степень экстинкции `U_max/U_min`; в дБ — `10·lg(ER)` |
| «гармоника n» | слагаемое вида `cos(nθ)`, `sin(nθ)` |

**Пререквизиты:** тригонометрия (формула понижения степени), линейная алгебра (метод наименьших
квадратов как решение нормального уравнения). Матрицы Джонса — только для §5.

## 2. Интуиция до формул: почему вообще что-то линеаризуется

Закон Малюса — это «яркость меняется как квадрат косинуса угла». Квадрат косинуса — вещь неудобная:
она нелинейна по θ. Но есть школьное тождество

    cos²α = ½(1 + cos 2α)

Оно говорит: **квадрат косинуса — это не «нелинейность», это просто косинус удвоенного угла плюс
константа.** Модуляция происходит не на частоте вращения, а на **удвоенной** частоте (столик
повернулся на 180° — картина повторилась, потому что поляризатор не различает «вперёд» и «назад»).

Дальше ключевой шаг. Пусть

    U(θ) = U_min + (U_max − U_min)·cos²(θ − θ₀)

Раскроем `cos²` и разложим `cos(2θ − 2θ₀)` по формуле косинуса разности:

    U(θ) = a₀ + a₁·cos 2θ + b₁·sin 2θ                                    (★)

где

    a₀ = (U_max + U_min)/2
    a₁ = ½(U_max − U_min)·cos 2θ₀
    b₁ = ½(U_max − U_min)·sin 2θ₀

Смотрите, что произошло. Неизвестный **угол θ₀ сидел внутри косинуса** — это делало задачу
нелинейной, требующей итераций, стартовых приближений и борьбы с локальными минимумами. После
разложения он «вышел наружу» и распределился между двумя **линейными** коэффициентами `a₁, b₁`.
Функции `1, cos2θ, sin2θ` от данных не зависят — это фиксированный базис. Значит (★) — это обычная
линейная регрессия.

Приём стандартный: в оптической метрологии это **фурье-анализ сигнала вращающегося поляризатора**
(rotating-analyzer ellipsometry, лок-ин на второй гармонике 2ω). Мы применяем его к угловой развёртке
вместо временнóй.

## 3. Замкнутые формулы (учебная, 3-параметрическая редакция)

**Прямой ход — линейный МНК.** Матрица плана `X` со столбцами `[1, cos2θᵢ, sin2θᵢ]`, веса
`W = diag(1/σᵢ²)`:

    p = (XᵀWX)⁻¹ XᵀWy ,        Cov(p) = (XᵀWX)⁻¹

Ни итераций, ни стартовой точки, ни мультистарта. Минимум один и он глобальный.

**Обратный ход — физика в замкнутом виде.** Обозначим `A = √(a₁² + b₁²)`:

| Величина | Формула |
|---|---|
| **офсет** | `θ₀ = ½·atan2(b₁, a₁)` (с точностью до 90°: сдвиг на 90° меняет максимум и минимум местами) |
| максимум / минимум | `U_max = a₀ + A`, `U_min = a₀ − A` |
| **контраст (экстинкция)** | `ER = (a₀ + A)/(a₀ − A)`, в дБ `10·lg ER` |
| **утечка по мощности** | `η² = U_min/U_max = (a₀ − A)/(a₀ + A)` |
| **утечка по амплитуде** | `η = √(U_min/U_max)` |
| глубина модуляции | `V = A/a₀`, причём `η² = (1−V)/(1+V)` |

**Ошибки — тоже замкнуто**, дельта-методом, без бутстрапа:

    σ²(θ₀) = [ b₁²·Var(a₁) + a₁²·Var(b₁) − 2a₁b₁·Cov(a₁,b₁) ] / (4A⁴)

Полезный частный случай: если углы равномерны и покрывают полный период `2θ`, матрица `XᵀX`
диагональна, `Var(a₁) = Var(b₁) = 2σ²/N`, `Cov = 0`, и всё сворачивается в

    σ(θ₀) = σ_U / (A·√(2N))       [радианы]

**Читается так:** точность офсета определяется отношением шума к *амплитуде модуляции* и числом
углов. Чтобы получить θ₀ с точностью 0.1° при N = 19 углах, нужно `σ_U/A ≈ 0.1°·(π/180)·√38 ≈ 1.1 %`.
Это ориентир для планирования измерения.

## 4. Точная редакция: почему нужна четвёртая гармоника

### 4.1. Откуда она берётся

В нашем пайплайне наблюдаемая строится **когерентно**: сначала складываются поля, потом берётся
квадрат модуля (`unified_optimizer/optimizer_2d.py:68`):

    E(θ) = t_perp·cos²θ + t_par·sin²θ

Применим то же тождество понижения степени к обоим слагаемым:

    E(θ) = A + B·cos 2θ ,     A = ½(t_perp + t_par),  B = ½(t_perp − t_par)

Поле — многочлен 1-й степени по `cos2θ`. Тогда

    U = |E|² = |A|² + 2Re(A·B̄)·cos2θ + |B|²·cos²2θ

и последнее слагаемое, снова по тому же тождеству, даёт `cos4θ`. Итого **точно**:

    U(θ) = c₀ + c₂·cos2(θ−θ₀) + c₄·cos4(θ−θ₀)                          (★★)

Никакого приближения: **квадрат модуля линейной по `cos2θ` величины есть тригонометрический многочлен
ровно 4-го порядка.** В координатах без офсета это 5 линейных коэффициентов:

    U = c₀ + a₂cos2θ + b₂sin2θ + a₄cos4θ + b₄sin4θ

### 4.2. Четвёртая гармоника не мала — она составляет четверть второй

Идеальный поляризатор (`t_par = 0`) даёт `U ∝ cos⁴θ` — то самое «двухполяризаторное» `cos⁴`, которое
проект уже использует (HN7 / Kaltenecker). Разложим:

    cos⁴θ = 3/8 + ½·cos2θ + ⅛·cos4θ    ⇒   A₄/A₂ = 0.25 ТОЧНО

**На реальных данных** (полный угловой диапазон, `a0_malus_harmonics_data.json`):

| Датасет | A₄/A₂ |
|---|---|
| 356att | 0.2498 |
| series1 | 0.2458 |
| series2 | 0.2549 |
| test_grid_40_20 | 0.2549 |

Отклонение от идеальных 0.25 — меньше 2 %. То есть четвёртая гармоника присутствует ровно в той
пропорции, которую предсказывает когерентная модель. **Отбросить её — значит выбросить 25 % сигнала.**

### 4.3. Что четвёртая гармоника даёт физически

Три коэффициента `c₀, c₂, c₄` взаимно однозначно связаны с тремя физическими величинами:

    |t_perp|²              = c₀ + c₂ + c₄
    |t_par|²               = c₀ − c₂ + c₄
    Re(t_perp·conj(t_par)) = c₀ − 3c₄

Отсюда — **модельно-независимо, одним линейным МНК**:

    η = √( (c₀−c₂+c₄) / (c₀+c₂+c₄) )
    cos Δφ = (c₀ − 3c₄) / √( (c₀+c₂+c₄)(c₀−c₂+c₄) )

Ключевое наблюдение: **относительная фаза каналов входит ТОЛЬКО через `c₄`.** В интенсивностной
(3-параметрической) картине фаз нет вообще — они там принципиально ненаблюдаемы. Поэтому учебная
линеаризация выбрасывает ровно ту наблюдаемую, которая несёт `δ₀` и `τ_leak` модели M5.

Это даёт **два бесплатных теста корректности**, которых в нелинейном фите нет:

1. **Неравенство Коши–Буняковского**: `|Re(t_perp·conj(t_par))| ≤ |t_perp|·|t_par|`, то есть
   `|cos Δφ| ≤ 1`. Нарушение = данные не описываются схемой «один вращающийся WGP × скаляр».
2. **Два независимых офсета**: `θ₀ = ½·atan2(b₂,a₂)` из второй гармоники и `θ₀ = ¼·atan2(b₄,a₄)`
   (mod 45°) из четвёртой. Обязаны совпасть. Расхождение = систематика по углу.

На данных при корректном взвешивании (см. §6.2) второй тест проходит с точностью **0.004–0.05°**
(356att −0.004°, series1 +0.051°, series2 −0.005°, test_grid +0.013°) — сильное подтверждение
внутренней согласованности.

## 5. Границы применимости: где линейность ломается, а где НЕТ

Здесь важно не переусердствовать с осторожностью. Часть «страшных» эффектов линейность **не** ломает,
и это надо знать точно.

### 5.1. НЕ ломают (доказано аналитически и проверено в самопроверке)

| Фактор | Почему не ломает |
|---|---|
| **Частотная зависимость утечки η(ν)** | на каждой частоте своя пара `t_perp(ν), t_par(ν)` → свои `c₀,c₂,c₄`. Структура (★★) сохраняется |
| **Фазовый член `e^{j(δ₀+2πν·τ_leak)}`** | входит в `Re(t_perp·conj(t_par))`, то есть только меняет `c₄`. Порядок многочлена прежний |
| **Суммирование по частотам (Парсеваль)** | сумма многочленов 4-го порядка — снова многочлен 4-го порядка. Проверка №5 самопроверки: относит. rms = 1.4e-16 |
| **Двух-WGP структура (теорема выравнивания T8)** | при выровненной оси второй WGP даёт скалярный множитель `t_perp2(ν)`, общий по θ. `η` и `cos Δφ` — **отношения** → к нему инвариантны |
| **Рассогласование φ₂ второго WGP** | `J(θ) = R(−θ)·diag·R(θ)` линейна по `cos2θ, sin2θ` при повороте одного элемента ⇒ `U` всё равно 4-го порядка. Меняются коэффициенты, не структура |
| **Нормировка на опорный сигнал** | общий по θ комплексный множитель, сокращается в отношениях |

**Отсюда сильное следствие об идентифицируемости** (это уже профиль сессии A): угловая развёртка на
одной частоте способна ограничить **не более 5 вещественных чисел**. Любая модель, вводящая на
фиксированной частоте больше независимых θ-независимых параметров, **структурно неидентифицируема из
углового скана** — сколько бы углов ни измерить. Это ровно то, почему `D_eff ↔ η` вырождены: они
конкурируют за одни и те же `c₀,c₂,c₄`.

### 5.2. Ломают

| Фактор | Механизм | Что делать |
|---|---|---|
| **Работа в дБ / логарифмах** | `ln` от многочлена — не многочлен. Проверка №6: rms = 1.73 дБ | фитовать **U**, а не `ln U`; логарифм только для показа |
| **Многолучевая интерференция между элементами (Фабри–Перо)** | множитель `(1 − r₁r₂e^{iψ})⁻¹` — рациональная функция от `cos2θ` ⇒ бесконечный ряд гармоник | в проекте HN3 отвергнута; при возврате — контроль по гармоникам ≥6 |
| **Нелинейность/насыщение детектора** | измеряется `f(U)`, а не `U` | контроль по гармоникам ≥6 |
| **Погрешность самогó угла** (люфт, ошибка позиционирования) | МНК считает θ точным (задача с ошибками в переменных) | смещение; нужна калибровка столика |
| **Деполяризация, конечная расходимость пучка с угловым разбросом** | эффективно свёртка по θ | гармоники сохраняются, но амплитуды подавляются — систематика в η |
| **Неполный угловой диапазон** | базисные функции перестают быть ортогональными | см. §6 — главный практический эффект |

## 6. Связь с текущей задачей A6

A6 (`A6_angle_symmetry`) проверяет симметрию `U(θ)` против `U(−θ)`, ищет офсет и экстинкцию.
Гармонический аппарат отвечает на её вопросы прямо и в замкнутом виде.

### 6.1. Обрезка диапазона `ANGLES_LIMIT_2D = (0, 90)` — количественно

На **полном** симметричном диапазоне (−90…+90) гармоники 2 и 4 почти ортогональны, и всё хорошо
обусловлено. На **урезанном** (0…90) — нет. Числа (`design_diagnostics`, чистая геометрия плана):

| Диапазон | углов | cond(XᵀX) | σ(θ₀) при 1 % шума |
|---|---|---|---|
| −90…+90 | 19 | **2.14** | 0.096° |
| 0…90 | 10 | **236.3** | 0.944° |

**Обрезка ухудшает точность офсета в 9.9 раза** — и это до всякого шума, чисто из-за плана
эксперимента. Хуже того, на урезанном диапазоне четвёртая гармоника уже **не ортогональна** второй,
поэтому её игнорирование даёт смещение θ₀ от **−2.3° до −4.8°** (по датасетам) — на порядок больше
самого обсуждаемого офсета.

А вот сам сдвиг оценки θ₀ при переходе полный → урезанный на реальных данных:

| Датасет | θ₀ полный | θ₀ на 0…90 | сдвиг |
|---|---|---|---|
| 356att | +0.901° | +0.214° | **−0.687°** |
| series1 | −0.546° | −0.194° | +0.351° |
| series2 | −0.463° | −2.565° | **−2.103°** |
| test_grid_40_20 | +0.599° | −0.321° | **−0.920°** |

**Это и есть главный вывод для A6.** Сдвиг от одной лишь обрезки углов сопоставим со всем спором о
величине `angle_offset` в A2 (там бассейны давали −1.294 / +0.219 / +0.584). Иначе говоря,
расхождение бассейнов могло быть артефактом усечённого углового плана, а не физикой.

### 6.2. Шкала весов решает, слышна ли тень

Побочный, но важный методический результат. Невзвешенный МНК по мощности взвешивает точку как `U²`,
поэтому яркая зона полностью заглушает тень — а вся информация об утечке сидит именно в тени.
Последствия на данных: для **series1 невзвешенная подгонка дала `|t_par|² < 0`** (физически
невозможно) — то есть η оттуда попросту не определена. При весах `σᵢ ∝ Uᵢ` (постоянная
**относительная** ошибка; задача остаётся линейной, веса не зависят от параметров) всё встаёт на
место, и два независимых офсета сходятся до сотых долей градуса (§4.3).

| Датасет | θ₀ равномерн. | θ₀ относит. | η равномерн. | η относит. |
|---|---|---|---|---|
| 356att | −0.097° | **+0.901° ± 0.184** | 0.0347 | **0.0127** |
| series1 | −0.286° | **−0.546° ± 0.248** | *отриц.* | **0.0121** |
| series2 | −0.654° | **−0.463° ± 0.198** | 0.0478 | **0.0130** |
| test_grid_40_20 | +0.211° | **+0.599° ± 0.327** | 0.0373 | **0.0329** |

Ошибка θ₀ — аналитическая (дельта-метод + поправка Бирджа на неизвестный масштаб шума), бутстрап не
требуется.

### 6.3. Модельно-независимая оценка `τ_leak`

Поскольку `cos Δφ(ν)` извлекается на каждой частоте линейным МНК, наклон `Δφ(ν)` по `2πν` даёт
`τ_leak` **без подгонки модели Бланко вообще**:

| Датасет | τ_leak (модельно-независимо) | нарушений `|cos Δφ| ≤ 1` |
|---|---|---|
| **356att** | **0.195 пс** | 12/151 (8 %) |
| series1 | 0.269 пс | 43/94 (46 %) |
| series2 | −0.104 пс | 20/129 (16 %) |
| test_grid_40_20 | 0.052 пс | 0/147 |

Для 356att получилось **0.195 пс против 0.19 пс у M5** — независимое подтверждение фазовой
компоненты утечки. Но универсальным результат назвать нельзя: series2 даёт отрицательное значение, а
у series1 почти половина частот нарушает неравенство Коши–Буняковского, то есть оценка там
недостоверна. Причина нарушений требует отдельной проверки (кандидаты: шумовой пол в глубокой тени
у беcплёночного series1; знаковая ветвь `arccos`). **Помечено как открытый вопрос, не как вывод.**

## 7. Что из этого следует делать

1. **Использовать order=4, а не order=2.** Учебная 3-параметрическая форма для наших данных
   систематически неверна: она игнорирует четверть сигнала и слепа к фазе утечки.
2. **Фитовать `U`, а не дБ**, с весами `σᵢ ∝ Uᵢ`.
3. **Гармонический разбор — как дешёвая предварительная диагностика перед любым нелинейным фитом.**
   Он даёт `θ₀`, `η`, `Δφ` за одно решение линейной системы, с аналитическими ошибками и без
   мультистарта — то есть даёт **тёплый старт и опорную точку**, которых требует урок A2
   («холодный старт завышает значимость»).
4. **Контроль остатка по гармоникам ≥6** как тест на выход за пределы модели (Фабри–Перо, нелинейность
   детектора).
5. Остаточное относительное rms при order=4 составляет 6–13 % — это **не** машинный нуль. Является ли
   это шумом уровня угла или физикой за пределами модели, решается в A6 (оценка повторяемости).

## 8. Открытые вопросы

- Нарушения `|cos Δφ| ≤ 1` у series1 (46 %) и series2 (16 %) — шумовой пол или реальный выход за
  схему «один вращающийся WGP × скаляр»?

  по модулю ветви — нужна процедура развёртки фазы по частоте.
- Согласуется ли `θ₀` из гармоник с независимой оценкой по точке симметрии (A6) — сверка запланирована
  в A6.
