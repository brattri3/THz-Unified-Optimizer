# Слой Antigravity — архив эпохи (июль 2026)

**Статус: историческое. Не исполнять, не пополнять.**
Основание — решение владельца **В-1 от 2026-08-08** (`coordination/QUESTIONS.md`).

## Что это было

До перехода на мультисессионный протокол Claude Code проект редактировался через два интерфейса
**Antigravity** (IDE и Chat). У них не было общего контекста, поэтому был заведён самодельный
механизм синхронизации из двух файлов:

| Файл | Где лежал | Что делал |
|---|---|---|
| `AGENTS.md` | `.agents/AGENTS.md` | правила для агентов: читать чейнджлог → работать → дописать чейнджлог → `git add .` + `git commit` + `git push`; артефакты дублировать в `docs/artifacts/` |
| `CHANGELOG.md` | корень репозитория | сам журнал: ~40 записей, **2026-07-16 … 2026-07-21** |

Побочный продукт этого механизма — каталог `docs/artifacts/` (65 файлов согласованными тройками
`plan_*` + `task_*` + `walkthrough_*`): его наполнение предписывал §3 `AGENTS.md`.

## Почему архивировано

1. **Механизм мёртв.** Последняя правка `AGENTS.md` — 2026-07-15, последняя запись
   `CHANGELOG.md` — 2026-07-21. Ни одна сессия Claude Code его не вела.
2. **Прямое противоречие действующему гардрейлу.** §2 обязывал агента делать `git push` после
   каждой задачи и `git add .` вслепую; действующее правило проекта — никаких `git push` без
   явного разрешения владельца и коммит только своих путей. Агент, честно исполнивший
   `AGENTS.md`, нарушал бы `CLAUDE.md`.
3. **`AGENTS.md` — распознаваемое имя.** Файл в `.agents/` подхватывается агентскими
   инструментами автоматически. Пока он лежал там, «отменён» существовало только на словах —
   перенос сюда и есть фактическая отмена.

## Что из этих правил сохранено

Одно, содержательное, а не процедурное: **обязательная статистика невязок** (§5 — проверка
нормальности, поиск структуры, карты остатков). Оно переписано как собственное правило проекта
и живёт в `CLAUDE.md`. Всё остальное (чейнджлог, автопуш, дублирование артефактов) отменено.

## Оговорка про кодировку

`CHANGELOG.md` — файл **смешанной кодировки**: начало UTF-8, записи от 2026-07-21 в cp1251
(их писал Antigravity IDE). Поэтому он перенесён сюда побайтово, без правки содержимого —
пометка «историческое» вынесена в этот README, а не в шапку самого файла. Если файл открыть и
пересохранить редактором в UTF-8, хвост превратится в мусор безвозвратно. Не пересохранять.
