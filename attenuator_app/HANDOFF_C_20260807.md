## 4. Техническое состояние на момент закрытия

- **Ветка `session/C` полностью влита в `main`** (`713f807` — предок `main`, проверено
  `git merge-base --is-ancestor`). Ничего не потеряно, мержить нечего.
- **Worktree `../TUO-C` чист, но отстал от `main` на 57 коммитов.** Работать в нём, не обновив,
  значит работать по данным и именам ДО переименования — то есть воспроизвести дефект из §2.
  Перед работой либо обновить (`git -C ../TUO-C merge main`), либо снести worktree и работать
  прямо на `main`: зона C с `main` не конфликтует, а изоляция ценой рассинхронизации данных
  здесь дороже, чем даёт.
- Рантайм приложения зависит **только от numpy**; `matplotlib` опционален (без него — ASCII).
  Это сознательное решение: приложение должно запускаться у покупателя без научного стека.

## 5. Два решения, которые нельзя потерять

1. **Относительный режим — по умолчанию, и это физика, а не удобство.** При SET ZERO общий
   множитель потерь `ℓ(ν)` и вносимое затухание `|t⊥|⁴` сокращаются тождественно (`|dA| = 1.8e-15`
   дБ при изменении `loss`/`gamma`). Следствие: хуже всех определённый параметр `gamma` из
   относительного режима **выпадает**, поэтому экстраполяция за полосу калибровки в нём на порядок
   надёжнее абсолютного режима.
2. **Неопределённость — по разбросу МЕЖДУ СЕАНСАМИ, а не по ковариации одного фита.** Разброс
   между сеансами шире паспортного 95 % CI в 3–27 раз по всем трём подгоняемым параметрам.
   Паспортный интервал получен на отфильтрованном по дрейфу ансамбле и оптимистичен для
   повседневной работы, где прибор переставляют и заново юстируют. Валидация выбор подтвердила:
   69/69 при запасе ×1.67.

Обоснования и 6 допущений, требующих подтверждения владельцем, — `STATE.md`.
