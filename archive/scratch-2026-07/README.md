# `scratch/` — разовый скрипт июля 2026

Заморожено 2026-08-09 (шаг 4 плана уборки).

В корне репозитория жил каталог с именем «черновик», содержавший **один** трекаемый файл —
`check_integral_zero.py` (2026-07-15, 1.5 КБ). Он импортирует `unified_optimizer` и проверяет
обнуление интеграла при `P_OPT = 15.50e-6`, `D_OPT = 4.045e-6` — те же значения, что в отчёте
`archive/results-2026-07/optimization_report.md`, то есть это разовая проверка того же прогона.

Владельца у файла не было: `scratch/` не входил ни в одну зону (`OWNERSHIP.md`), поддерживать его
никто не был обязан. Каталог убран целиком, файл сохранён здесь.

**Куда класть такое впредь.** Разовые проверки — в `research/experiments/` (зона A), под своим
именем и с записью в `research/logs/RESEARCH_LOG.md`. Каталогов «на черновики» в корне
репозитория не заводить: у всего в git должен быть владелец (`OWNERSHIP.md`, раздел «Остальное
дерево»).
