# Учебный курс (LaTeX) — как собирать и как вести

Зона D (`research/paper/**`). План документа и статус параграфов — `PLAN.md`.

## Сборка

```powershell
.\build.ps1              # только LaTeX (быстро)
.\build.ps1 -Figures     # пересобрать все графики, затем LaTeX
.\build.ps1 -Clean       # убрать промежуточные файлы
```

Результат — `main.pdf` в этом каталоге.

**Технические особенности установки, о которые легко споткнуться:**

- `latexmk` в этой установке MiKTeX **не работает** — ему нужен `perl`, которого в системе нет.
  Поэтому `build.ps1` вызывает `pdflatex` напрямую, **три прохода** (оглавление и перекрёстные
  ссылки должны устояться).
- Движок — **pdflatex** с `T2A`/`babel`, как и seed-документ проекта `problem_statement.tex`.
  Не XeLaTeX: меньше внешних зависимостей, кириллица работает из коробки.
- **Ударения над кириллицей (`\'а`) ломают сборку** с `Invalid UTF-8 byte sequence`. Писать без
  них.
- Графики строятся `.venv` проекта (matplotlib), выводятся в **PDF** — документ печатный,
  вектор не пикселизуется.

## Правила ведения

1. **Один параграф за итерацию.** Написать `sections/NN_*.tex`, собрать его графики,
   раскомментировать `\input` в `main.tex`, скомпилировать, отправить PDF владельцу и
   **ждать его комментария** (регламент заказан владельцем 2026-08-05).
2. **Нумерация с нуля.** В `main.tex` стоит `\setcounter{section}{-1}`, поэтому §0 —
   электродинамика, §1 — Джонс и так далее: номера в документе совпадают с номерами модулей
   учебной программы.
3. **Новых расчётов не делаем.** Скрипты в `figures/` — визуализация уже посчитанных чисел либо
   чистой математики (тождества, геометрия матрицы плана, масштабы длин волн). Всё, что требует
   прогона модели по данным, заказывается у Сессии A через `coordination/HANDOFFS.md`.
4. **Каждое число — со ссылкой на артефакт.** Для этого есть макрос `\artifact{...}`; в конце
   параграфа — таблица «Источники фактуры».
5. **Сверяться с запрещённым списком** `research/paper/STATE.md §3.1` перед каждым параграфом
   (отозванные и смещённые числа).
6. **Единая нотация — только через макросы** `preamble.tex` (`\Deff`, `\tperp`, `\tleak`, …).
   Менять обозначение — в одном месте, а не поиском по тексту.

## Врезки

| Окружение | Назначение |
|---|---|
| `intuition` | суть простыми словами, без формул |
| `strict` | та же мысль строго |
| `projectfact` | реальное число проекта + артефакт |
| `warning` | типичная ошибка или ограничение |

Все принимают необязательный аргумент-суффикс к заголовку:
`\begin{warning}[: здесь ошибаются почти все]`.

**Врезку, которую разрывает плавающий рисунок**, удерживают целиком через
`\needspace{8\baselineskip}` перед ней.

## Отношение к `primers/*.md`

Markdown-методички — рабочая форма (правки, git-дифф, ссылки других сессий); LaTeX — издательская.
Фактура первична в markdown, подача первична в LaTeX. Ошибка в числах правится **в обоих** файлах
одним коммитом.
