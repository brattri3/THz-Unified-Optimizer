## 0. Ответ в двух фразах

Аппарат A0 линеаризует **мощность** `U = |E|²` и потому работает в базисе 4-го
порядка. Но данные проекта комплексные до самого конца, и если линеаризовать
**само поле**, базис становится 2-го порядка, а на выходе получаются
комплексные `T⊥(ν)`, `T∥(ν)` — с фазами, без ветви `arccos`, с тождественно
выполненным неравенством Коши — Буняковского.

Это **этап 1** двухэтапной схемы: спектры каналов восстанавливаются
модельно-независимо, и только потом к ним подгоняется модель. Этап 2 —
отдельная задача.

## 1. Почему двухэтапность здесь точна, а не приближённа

Модель проекта **факторизуется тождественно** (`research/experiments/model_core.py:296-297`):

```
E(θ,ν) = cos²(θ−θ₀)·T⊥(ν) + sin²(θ−θ₀)·T∥(ν)
T⊥ = t_perp(P,D,ν)·loss(ν)·e^{−2πiντ}
T∥ = [t_par(P,D,ν) + η₀ν^a e^{i(δ₀+2πντ_leak)}]·loss(ν)·e^{−2πiν(τ+τ_par)}
```

Все физические параметры входят **только** через два комплексных спектра, а
`angle_offset` — только через угловую часть. При фиксированном `θ₀` модель
целиком лежит в трёхмерном `span(X)` углового базиса, поэтому побинные
коэффициенты с информационными матрицами `{ẑ_j, N_j}` — **достаточная
статистика** угловой развёртки:

```
χ²_global(p) = Σ_j [ẑ_j − z_j(p)]^H N_j [ẑ_j − z_j(p)] + RSS⊥,   ∂RSS⊥/∂p = 0
```

Двухэтапная схема тождественна глобальному фиту, а не приближает его.

**Побочный выигрыш крупный.** `angle_offset` уходит из нелинейного поиска в
замкнутую формулу, а это главный документированный источник мультимодальности
проекта (A3: 3–20 бассейнов на 21 старт, только 22.2 % стартов достигают
глобального). Плюс восстановленные `T⊥`, `T∥` **стационарны** по ошибке `θ₀`:
`dB/dθ₀ ≡ 0` в точке решения, ошибка входит вторым порядком (проверено —
`e(2δ)/e(δ) = 4.0000`).

## 2. Аппарат

`E(θ) = A + B·cos2(θ−θ₀)`, разложение по базису `{1, cos2θ, sin2θ}` даёт три
**комплексных** коэффициента:

```
z₀ = A,   z_c = B·cos2θ₀,   z_s = B·sin2θ₀
```

Матрица плана вещественная, поэтому `Re` и `Im` решаются одной системой;
«комплексный МНК» в эрмитовом смысле не нужен. Для кругового шума
`Cov(z) = (XᵀWX)⁻¹` — тоже вещественная, псевдоковариация нулевая.

**Угловой офсет — в замкнутой форме.** Вектор `(z_c, z_s) = B_j·u`, где
`u = (cos2θ₀, sin2θ₀)` вещественный и общий для всех бинов, поэтому

```
R_j = [[|z_c|², Re(z̄_c z_s)], [·, |z_s|²]] = |B_j|²·u uᵀ      — точно ранга 1
M = Σ_j w_j R_j,   u = старший собственный вектор
```

`λ₂/λ₁` — прямая скалярная мера нарушения гипотезы единого `θ₀`, то есть
**модельно-независимый тест HN13**. Ветвь `u` фиксируется требованием
`Σ|T⊥|² > Σ|T∥|²` (иначе каналы меняются местами, а `θ₀` уезжает на 90°).

Каналы: `T⊥ = z₀ + B`, `T∥ = z₀ − B`, ковариация `Cov2 = M C Mᵀ` с
`M = [[1,1],[1,−1]]`.

## 3. Что метод даёт сверх мощностной версии

### 3.1 Коши — Буняковский выполняется тождественно

В поле `|cos Δφ| ≤ 1` и `|T∥|² ≥ 0` верны **по построению**: фаза берётся как
аргумент комплексного числа, а не из отношения трёх независимо шумящих
коэффициентов. Монте-Карло (21 угол, `η` = 0.037, рецепт A):

| SNR тени | нарушений: поле | нарушений: мощность | `\|T∥\|² < 0` |
|---|---|---|---|
| 10 | 0 % | 10.3 % | 0 % |
| 3.6 | 0 % | 36.1 % | 0 % |
| 2 | 0 % | 44.4 % | 0.6 % |

**На реальных данных подтверждено точно:**

| Датасет | мощность (наша реализация) | A0 ранее | поле |
|---|---|---|---|
| `att-11-16-356` | 12/151 | **12/151** | **0/151** |
| `att-11-16-s1` | 43/94 | **43/94** | **0/94** |

Мощностная ветка воспроизводит A0 бит-в-бит, значит сравнение честное.
**Это отвечает на открытый вопрос NOTE §8** («нарушения у series1 46 % —
шумовой пол или выход за схему?»): шумовой пол, и предсказывается
количественно по SNR.

### 3.2 Фаза знаковая, ветвь `arccos` не нужна

`Δφ(ν) = arg T⊥ − arg T∥` измеряется прямо; развёртка по частоте — по кускам
валидных бинов со сшивкой целым `2πk` (водяная маска рвёт ось).

Измеряемая величина — **наклон** `Δφ` по частоте, `τ_Δφ`. Связь с параметром
модели требует модели и выписана явно: в конвенции M5 утечка входит как
`e^{+2πiντ_leak}`, а задержка канала как `e^{−2πiντ}`, откуда
`τ_Δφ = τ_par − τ_leak`, и при `τ_par ≈ 0` имеем `τ_leak = −τ_Δφ`.

| Датасет | `τ_leak` (поле) | ранее |
|---|---|---|
| `att-11-16-356` | **+0.1871 ± 0.0053 пс** | 0.195 (A0, через `arccos`), 0.19 (M5) |
| `att-11-16-s1` | **+0.0390 ± 0.0058 пс** | 0.269 (A0) — но там 46 % нарушений, оценка была признана недостоверной |
| `test_grid_33_11` | +0.0192 ± 0.0006 пс | — |
| `specac-2` | +0.0350 ± 0.0011 пс | — |

Существенно: `τ_leak` здесь **не требует закрепления `D_eff`**, тогда как в M5
он идентифицируем только при пине (HN8).

### 3.3 Четвёртая гармоника в поле обязана быть нулём

В мощности `A₄/A₂ = 0.25` — ожидаемая физика когерентной композиции, и теста
не выходит. В поле любой значимый `(z_c4, z_s4)` есть выход за схему «один
вращающийся WGP × скаляр». Измеряется в единицах `χ²` на степень свободы.

## 4. Модель шума: калибруется, а не назначается

Это оказалось главным практическим вопросом.

`σ²(θ,ν) = κ·tnoise(ν)·(1+|t|²) + (ε·|t|)²` — аддитивный шум детектора плюс
мультипликативный дрейф уровня трассы. Обе компоненты **измерены**:

* `κ = 4/π`: `noise_floor` берёт `nfa` как среднее **модуля** FFT
  (`a3_eps_stability.py:133`), а для кругового комплексного шума
  `E|n| = σ√(π/4)`. Без поправки `tnoise` занижен по дисперсии в 1.27 раза.
* `ε` подбирается из `χ²/dof = 1` (`calibrate_noise`).

**Почему это не косметика.** Вес тени относительно яркой зоны у чисто
аддитивной и у смешанной модели различается на два порядка, и от него заметно
зависит `θ₀`. На `test_grid_33_11`:

| веса | `θ₀` | `χ²/dof` |
|---|---|---|
| чисто аддитивные | −1.3837 ± 0.0079 | 8.68 |
| `∝|t|²` (рецепт A) | −1.2700 ± 0.0076 | — |
| **откалиброванная смесь (ε = 1.55 %)** | **−1.2723 ± 0.0063** | **1.00** |
| эталон A13 (мощность) | −1.2770 ± 0.0354 | — |

Откалиброванная модель воспроизводит эталон с расхождением 0.13σ при ошибке в
5.6 раза меньшей. И `ε = 1.55 %` независимо согласуется с прямо измеренным
дрейфом уровня трассы (`|g|` rms 1.04 %, `arg g` rms 0.92°).

**Независимая проверка — по повторам.** У `specac/exp_data_2` 2–4 повтора на
угол, то есть впервые в проекте есть прямая оценка шума **уровня угла** (её
отсутствие заставляло A6/HN13 выносить вердикт по консервативной верхней
границе). Отношение «реальная дисперсия по повторам / модельная»:

| модель шума | отношение |
|---|---|
| чисто аддитивная | **28.7** |
| откалиброванная | **0.63** |

`ε` калибровался по внутренней согласованности фита, а проверен по внешней,
независимой величине — они сошлись.

**Отношение к вердикту C-5.** Это уточняет, а не отменяет его. Там речь шла о
мощностном фите, где `σ` по шумовому полу двигает саму оценку `η`. В поле общий
множитель `κ·tnoise(ν)` от угла не зависит и в решении сокращается; опасность
иная — не сам шумовой пол, а **полнота модели шума**.

## 7. Что осталось открытым

1. **Четвёртая гармоника на `test_grid_33_11`: 3.3 на степень свободы** при
   ожидаемой 1. После снятия дрейфа уровня угла падает до 0.7, то есть большей
   частью это дрейф — но не целиком, и остаток не объяснён. На `specac-2`
   аномалии нет (0.9). Требует проверки, выводом не является.
2. **Остатки ненормальны** на обоих датасетах: `std` ≈ 0.98 (то есть масштаб
   верен), но эксцесс +2.2 и +4.7, Шапиро `p → 0`. Тяжёлые хвосты. Это
   согласуется с вердиктом HN6 «взвешивание не чинит нормальность» и означает,
   что часть невязки структурная.
3. **Минимум `|E|` внутренний в 82–84 % бинов**, медианный сдвиг от `θ₀+90°`
   составляет 3.08° (`test_grid_33_11`) и 3.89° (`specac-2`). Формула
   `x* = −(|T⊥|²−|T∥|²)/|T⊥−T∥|²` даёт этот сдвиг без единого нового
   параметра, а условие внутренности сводится к `cos Δφ < η`. Это кандидат-
   объяснение «необъяснённых ~3°» у `test_grid_33_11` (HANDOFF_A §5 п.5) —
   **но сверка конвенций углов не сделана, и как вывод это не заявляется.**
4. **`τ_leak` у `att-11-16-s1`**: 0.039 ± 0.006 против 0.269 у A0. Прежняя
   оценка получена там, где 46 % бинов нарушали Коши — Буняковского, то есть
   была недостоверна по признанию самого NOTE §6.3. Новая — первая достоверная,
   но требует независимого подтверждения.

## 9. Этап 2 — опорная записка (решение владельца 2026-08-16: делать следующим)

> **ЭТАП 2 СДЕЛАН 2026-08-16, задача A23.** Результаты, находки и открытые
> вопросы — `NOTE_stage2_blanco.md`, реализация — `a23_stage2_blanco.py`.
> Раздел ниже оставлен как проектная записка; в нём **одна ошибка**: проверка
> `χ²_global − χ²₂ = const` в `field_linearization.selftest` НЕ стояла, она
> реализована в `a23_stage2_blanco.selftest` (проверки 2-3). Ещё одно ожидание
> не подтвердилось: изъятие `angle_offset` мультимодальность **не сняло** —
> на `test_grid_33_11` в лучший бассейн попадает 19.0 % стартов против 22.2 %
> у глобального фита в A3.

Всё, что нужно для холодного старта, собрано здесь, чтобы не поднимать заново.

**Вход.** `a22_field_vs_power.run_field(...)` уже возвращает `T_perp`, `T_par`
(комплексные, длина = число валидных бинов) и `Cov2` — вещественную `(nbin,2,2)`
ковариацию пары каналов. Загрузка данных — `load_dataset(name)`, она сама
разводит два пути (`exp_builder` и `scan_loader`) и отдаёт `tnoise`.

**Модель берётся из зоны B без единой строки новой физики.** При
`angle_offset = 0` строка `θ = 0` даёт ровно `T⊥`, строка `θ = 90` — ровно `T∥`
(`model_core.py:285-297`, там `cos²0 = 1`, `sin²0 = 0`):

```python
E = model_core.compute_grid([0.0, 90.0], freqs, p, d, ..., angle_offset=0.0)
T_perp_model, T_par_model = E[0], E[1]
```

Это гарантирует бит-в-бит ту же физику, что у глобального фита, и не требует
править `model_core.py` (зона B).

**Целевая функция:**

```
χ²₂(p) = Σ_j 2·ΔT_j^H · Cov2_j⁻¹ · ΔT_j ,  ΔT_j = (T̂⊥,j − T⊥(ν_j;p), T̂∥,j − T∥(ν_j;p))
```

Для `lmfit.leastsq` — вектор невязок `L_j = cholesky(2·Cov2_j⁻¹)`, стек
`[Re(L_j ΔT_j), Im(L_j ΔT_j)]`. Множитель 2 — тот же, что в `solve_bins`
(`σ²` есть полная дисперсия комплексной величины), и проверяется требованием
`E[χ²] = dof`.

**Параметры.** `P_um` прибит; `D_um`, `loss_factor`, `tau_ps`, `tau_par_ps`,
`eta0`, `eta_exp`, `delta0`, `tau_leak` свободны; `gamma` прибит 2.0 (HN11).
**`angle_offset` изъят** — он уже применён на этапе 1, и это главный выигрыш
схемы. Тёплый старт для `eta0`, `eta_exp`, `delta0`, `tau_leak` берётся прямо
из `logratio_regression` этапа 1 — четыре из девяти параметров входят с честной
затравкой и честной априорной ошибкой.

**Мультистарт обязателен** (урок A3: 3–20 бассейнов на 21 старт, только 22.2 %
достигают глобального): сетка `D_seed ∈ {0.3, 0.6, 0.9}·D_phys` ×
`eta0_seed ∈ {0, 0.005, 0.03}` × `tau_leak_seed ∈ {0, 0.19}`, минимум 18
стартов; в артефакт идут ВСЕ, с разрывом AIC между бассейнами и долей стартов,
попавших в лучший.

**Чем проверять, что схема тождественна глобальному фиту:**

1. алгебраически — `χ²_global(p) − χ²₂(p) = const` для случайных `p`
   (уже стоит в `selftest`, машинный нуль);
2. численно — глобальный комплексный фит на тех же данных с `angle_offset`,
   прибитым к `θ₀` этапа 1: параметры обязаны совпасть до ~1e-6 относительно.
   Образец такого фита без правки зоны B — `a3_eps_stability.py:196`;
3. диагностика — тот же фит со свободным `angle_offset`: расхождение его `θ₀` с
   этапом 1 показывает, насколько модель Бланко тянет угловой офсет на себя.

**Отрицательный контроль.** Корреляция `D_um ↔ eta0` обязана остаться ≈ −1 на
плотных образцах. Если «развяжется» — искать ошибку, а не праздновать. У
`test_grid_33_11` (разреженный, D/P = 0.333) она и так −0.429, там развязка
настоящая.
