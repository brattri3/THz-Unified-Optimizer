# CLAUDE.md — THz-Unified-Optimizer

Извлечение параметров проволочных поляризаторов (период `P`, эффективный диаметр `D_eff`) из данных
THz-TDS. Ядро — аналитическая модель **Бланко 1986** в формализме матриц Джонса, поверх неё —
Друде, степенное рассеяние `ν^γ`, фазовые задержки, утечка параллельного канала.

Язык документации и коммитов — **русский**.

## Твой старт

Над проектом работают несколько сессий-ролей (`A`/`B`/`C`/`D`/`L`/`P` + оркестратор `ORCH`),
делящих этот репозиторий.

1. Назови сессию: `claude -n <имя роли>` или `/rename`. Имена: `a-model`, `b-core`, `c-app`,
   `d-paper`, `l-lit`, `p-report`, `orch`.
2. Один раз посмотри `claude agents --json`: если в этом `cwd` уже висит сессия с твоим именем и
   статусом `busy` — не начинай, скажи владельцу.
3. **Прочитай `coordination/roles/<ID>.md` — это единственный обязательный файл.** Там твоя зона,
   что открыто, что дальше и куда идти за подробностями.

Больше при старте читать нечего. Всё остальное — по поводу, см. указатель ниже.

> Координацию сессий **как процессов** ведёт сам Claude Code; наш регламент координирует только
> **предметную** работу. Локов, heartbeat и реестров ников в проекте нет (отменены 2026-08-15).
> Встретишь в старом документе «занять лок», «обновить heartbeat», «зарегистрировать ник» —
> **это наследие, не исполняй**.

## Гардрейлы — нарушение необратимо

- `data_pool/**` и `unified_optimizer/**` — **только чтение**. Данные добавляет владелец-человек;
  правка продакшна меняет базовую линию всех фитов. Единственное исключение: роль B по **разовой**
  санкции владельца на конкретный дефект.
- `git push` — **только с прямого разрешения владельца**. Форс, `rm -rf`, переписывание истории —
  никогда.
- Модель правится только в research-копиях (`research/experiments/model_*.py`,
  `research/two_wgp/model_2wgp.py`); оригинал не редактируется.
- **Работай только в своей зоне.** Просьбу вне зоны не выполняй: объясни, чья это зона, запиши в
  `coordination/HANDOFFS.md`, предложи переключиться. Не уверен, чья зона — спроси.
- Коммит: префикс `[<ID>]` + трейлеры **последним абзацем, без пустой строки внутри**:
  `Session: <ID>` и `Reason: <в одну строку>`. Коммить только свои пути, `git add -A` — нет.
- Любой вывод о качестве подгонки подкрепляется **статистикой остатков**, а не одним значением
  невязки: нормальность (Шапиро — Уилк / Харке — Бера, Q-Q), структура (residuals vs frequency —
  волна или тренд читаются как неполнота физики), карты остатков в артефакте задачи.

```powershell

.venv\Scripts\python.exe -m unified_optimizer.run_pipeline --method 1d   # 2d ветка падает
.venv\Scripts\python.exe -m pytest unified_optimizer/tests -q            # ⚠ pytest в .venv нет
```

Скрипты в `research/` запускать **всегда из корня репозитория** — они вставляют корень в `sys.path`
(`parents[2]`), из другого CWD ломаются пути к данным.

## Данные

`data_pool/{dataset}_{angle}deg_rep{N}_{sig|bg}.txt` — две колонки (время, поле). `DataManager`
сканирует `data_pool/` рекурсивно и разбирает **имя файла**, а не путь: подкаталоги подхватываются
автоматически, файлы вне шаблона молча пропускаются. Микрофото (`.bmp`, ~630 МБ) в git не
трекаются — на ноутбуке их нет; CSV-обмеры трекаются. Карта — `data_pool/MICROSCOPY.md`.

## Физика: что не переоткрывать

Опорная модель **M5** = Бланко + Друде + рассеяние `ν^γ` + приколоченный `D_eff` + явная утечка.
Установлено: утечка `t_par` универсальна (6 образцов); `D_eff ↔ η` вырождены полностью
(корреляция ±1.0) — свободный фит обоих бессмыслен; теорема выравнивания доказана; отвергнуты
HN3, HN4, HN9, HN10, HN11. Открыта загадка `D_eff` (`D_eff/D_phys ≈ 0.43–0.64`).

**Полностью и с числами — `research/SYNTHESIS.md`. Читать до любой новой гипотезы.**
Методическое: угловые добавочные параметры мультимодальны — всегда мультистарт, холодный старт
завышает значимость.
