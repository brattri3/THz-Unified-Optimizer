## Образец

| Параметр | Значение | Источник |
|---|---|---|
| Период `P` | 33 мкм | владелец, 2026-08-06 |
| Диаметр проволоки `D` | 11 мкм | владелец, 2026-08-06 |
| `D/P` | **0.333** | — |
| Светлая апертура оправы | ⟨заполнить в META⟩ | — |

**Чем ценен:** это самый разреженный образец проекта. Прежний диапазон `D/P` — 0.416…0.710
(семь образцов), новый расширяет его вниз почти вдвое. Закон `D_eff = D_phys(1 − 0.85·D/P)`
проверялся только внутри старого диапазона, поэтому точка при 0.333 — настоящая экстраполяционная
проверка, а не ещё одно подтверждение внутри интервала.

⚠ **Погрешности `P` и `D` не заданы.** Для полного M5-фита геометрия нужна с приором
(`fit_lib.GEOMETRY`). Если есть микрофото — их разбор даст `P` и `D` с ошибкой; если чисел
неоткуда взять, годится и оценка по дифракции лазерной указки (`d·sinθ = mλ`, методика —
`research/two_wgp/a8_diffraction_zones.py`; для `P = 33 мкм` при `λ = 650 нм` и экране `L = 315 мм`
порядки `+1` и `−1` разойдутся примерно на **12.4 мм**).

## Имена файлов

Прибор пишет журнальную нумерацию `NNN_aXX.txt` (сигнал под углом XX), `NNN_bg.txt` (фон),
`NNN_META.txt` (метаданные). `DataManager` такие имена не видит — ему нужно

```
test_grid_33_11_<angle>deg_rep<N>_<sig|bg>.txt
```

Как и в `purewave`/`specac`, канонические имена появятся **копиями** рядом с оригиналами:
журнальная нумерация — единственная связь трасс с файлами `NNN_META.txt`, поэтому оригиналы
не переименовываются и не удаляются. Соответствие «журнальный номер → (угол, реплика, фон)»
уже зафиксировано машинно в `research/two_wgp/plan_test_grid_33_11.json`, так что нормализация после
съёмки будет механической.

## Чего делать НЕ надо (уроки предыдущих образцов)

- **Не измерять только диапазон (0°, 90°).** Он даёт `cond(XᵀX) = 236.3` против 2.14 у полного,
  и угловой офсет становится в 9.9 раза хуже определён ещё до всякого шума.
- **Не переставлять образец посреди прогона без якорей.** На `purewave` переустановка изменила
  утечку в 2.3 раза; отличить это от физики удалось только благодаря π-периодичности.
- **Не пропускать проверку центровки на оси вращения.** Смещённый узкий пучок при повороте
  описывает окружность по апертуре, и тогда угол и участок решётки перепутаны — на `purewave`
  из-за этого пришлось отозвать уже опубликованный вывод (гипотеза HN15 вернулась в статус
  «не проверена»).
