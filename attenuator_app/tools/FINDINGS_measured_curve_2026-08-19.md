# Находки прототипа `measured_curve.py` — передача Сессии A (2026-08-19)

## Контекст

Владелец 2026-08-17 санкционировал быстрый прикладной прототип: угловая и спектральная
кривая аттенюатора **прямо по измерениям** серии `ATT-11-16-CA85_02721_s2`
(`data_pool/two_wgp_attenuator/ATT-11-16-CA85_02721_s2/`, происхождение и конвертация —
`000_META.md` там же), с явным пропуском сверки против спорной двухэтапной модели зоны A
(`research/two_wgp/NOTE_stage2_blanco.md`) — «вопросы верификации оставить на будущее».

Задача была прикладной: показать в еженедельном отчёте рабочую кривую и уметь руками
подстраивать параметры. По ходу работы вскрылось несколько физических находок, которые
зона A может счесть релевантными для своей ветки исследования — они ниже. Это НЕ попытка
воспроизвести или оспорить модель зоны A: используется только некомпрометированное ядро
(`core/blanco.py:dressed_t`, БЕЗ `eta0`/`tau_leak`/`tau_par` — та же оговорка, что и в
`research/two_wgp/NOTE_stage2_blanco.md` про спорную феноменологию).

Код: `attenuator_app/tools/measured_curve.py` (библиотека + CLI), `measured_gui.py`
(интерактивный GUI, ручная подстройка P/D/потери/gamma/theta0). Не часть клиентского
`attenuator_app.gui`/`cli` — лабораторный инструмент.

## Метод (коротко)

1. Гармонический фит закона Малюса по времени и по спектру (`track_viewer.core.fit_malus`,
   уже сверенный зоной A 12/12, переиспользован как есть) → офсет ротатора `theta0`,
   модельно-независимые энергетические каналы `I_perp(ν)`, `I_par(ν)`.
2. Полная Джонс-матричная модель схемы S1 (`WGP1(θ) → WGP2(статичен, выровнен с
   детектором) → детектор`), оба WGP считаются **идентичными** (одна геометрия
   `P, D, loss_factor, gamma`, обоснование — паспорт: «Оба WGP аттенюатора ИДЕНТИЧНЫ»,
   `data_pool/two_wgp_attenuator/README.md`).
3. `scipy.optimize.least_squares`, 4 свободных параметра, невязка нормирована отдельно по
   каналам.

## Находки

### 1. Канал `I_perp` — НЕ `|t_perp|²` одного WGP, а `|t_perp|⁴`

Вывод из Джонс-матриц (WGP2 идентичен WGP1, выровнен с детектором):

```
E(θ,ν) = t_perp(ν) · [t_perp(ν)·cos²(θ-θ0) + t_par(ν)·sin²(θ-θ0)]
I(θ,ν) = |E|² = |t_perp(ν)|² · |t_perp(ν)·cos²(θ-θ0) + t_par(ν)·sin²(θ-θ0)|²
```

При θ=θ0 и θ=θ0+90°, то есть ровно там, откуда модельно-независимая декомпозиция берёт
`I_perp`/`I_par`:

```
I_perp = |t_perp|⁴          (не |t_perp|², как для одиночного WGP)
I_par  = |t_perp|²·|t_par|²  (не |t_par|²)
```

Первая версия фита подгоняла `|t_perp|²`/`|t_par|²` напрямую к этим каналам — т.е. неявно
считала, что в тракте один WGP, а не два. Итог: подогнанные `P,D,потери,gamma`
воспроизводили ЧАСТОТНУЮ ФОРМУ каналов почти идеально (спектральные панели совпадали
визуально), но при обратной реконструкции абсолютной угловой кривой давали пик ~0.88 вместо
измеренных ~0.98 — задвоение/недобор степени было замаскировано тем, что подгонка одной
"эффективной" пары `t_perp,t_par` под произведение двух одинаковых WGP работает прилично
именно по форме, но не по абсолютному уровню. Исправлено (`blanco_channel_model` в текущем
коде).

### 2. Сходимость `P` далеко от паспорта, `D` — близко

После исправления п.1: `P ≈ 33–41 мкм` (паспорт 16), `D ≈ 10–13 мкм` (паспорт 11, близко).
Устойчиво к границам полосы (0.2–1.5 и 0.3–1.5 ТГц дают близкие числа), к отбраковке
выбросов, к весам в целевой функции — то есть это не шум подгонки, а, по-видимому, реальная
слабая обусловленность самой 4-параметрической задачи (тот же класс вырожденности
`D_eff ↔ η`, что уже задокументирован в `research/SYNTHESIS.md`, но для другой постановки —
здесь оба WGP формально идентичны и совместно ограничены). **Загадку сходимости `P` в этой
постановке не решал** — предлагается зоне A, когда обновится лимит; сюда это не входило по
санкции владельца.

### 3. Пять линий поглощения атмосферного водяного пара в `I_perp`

Частоты 1.097, 1.113, 1.159, 1.166 и 1.412 ТГц дают выбросы далеко за 3σ (робастная σ через
MAD) в канале `I_perp`, совпадающие со стандартным набором линий поглощения H₂O в
непродуваемом ТГц-тракте. Не шум измерения и не дефект решётки — отдельная атмосферная
физика, которую модель Бланко не описывает. Реализована отбраковка (3σ по MAD, окно
дополнено соседними бинами — линия имеет ширину) **только по `I_perp`**, тот же набор бинов
по индексу частоты перенесён на `I_par` (общая причина — ослабление всего импульса на этой
частоте, свойство тракта, не поляризации). Отдельная 3σ-отбраковка НА `I_par` пробовалась и
оказалась негодной: там расхождение с моделью — широкий систематический уход почти на трети
верхней полосы, а не спайки, отбраковка спрятала бы неполноту модели, а не выброс.

Если у зоны A есть другие спектры этого прибора без продувки азотом — стоит проверить те же
частоты; если совпадут, это подтверждает атмосферное происхождение и открывает дешёвый способ
чистки данных на будущее (список частот фиксированный, не требует подгонки под каждый набор).

### 4. Расхождение пика ~5-6% в абсолютном режиме — это не невязка фита, а теорема Парсеваля

`T_time` (интеграл импульса по времени, `physics.py`) по Парсевалю равен **взвешенному**
(весом `|Ê_ref(ν)|²`, реальным спектром референсного импульса) среднему `T(ν)` по **всей**
записанной полосе. Модельная угловая кривая изначально усреднялась ПЛОСКО (без веса) только
по узкой полосе фита каналов (0.3–1.5 ТГц, ~75% энергии импульса) — отсюда системное
занижение пика в абсолютном режиме на ~5-6%, никак не связанное с качеством фита.

Проверено экспериментально: увеличение веса канала `I_perp` в целевой функции фита (от 1 до
50×) пик модели вообще не сдвигает (0.8847 → 0.8846), только разрушает согласие `I_par`
(RMS невязки 0.68 → 8.47 дБ) — то есть это не вопрос перевеса каналов в оптимизаторе.
Исправление — не в фите, а в реконструкции: угловая кривая теперь усредняется по ВСЕЙ
записанной полосе (`reference_power_spectrum()`, средний спектр мощности `bg`-трасс дороги,
DC-бин исключён) с весом `|Ê_ref(ν)|²`, согласованно с определением `T_time`. После этого пик
модели практически совпадает с данными и фитом Малюса без изменения самих `P,D,потери,gamma`.
